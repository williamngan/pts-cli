Pts. CLI Code README GitHub

Render Pts.js from the command line.

Generate images and SVG in Node without running a browser.

Render a file 
$ npx pts-cli circle.mjs

pts-output/circle-<render-id>.png

Write a JavaScript file

Export one function and use ordinary Pts drawing code inside it.

circle.mjs 
export default function run({ Pts, space, form }) {
  const { Circle } = Pts;

  space.add(() => {
    form
      .fillOnly("#7566ff")
      .circle(
        Circle.fromCenter(
          space.pointer,
          48
        )
      );
  });
}

Render it

npx pts-cli circle.mjs \
  --out circle.png \
  --out circle.svg

npx pts-cli circle.mjs \
  --size 1200x630 \
  --background "#10283a" \
  --out card.png

Size and background are optional. They default to 800 × 600 and transparent.

Use the same file in a browser

import { mountScene } from
  "pts-cli/browser";
import run from "./circle.mjs";

await mountScene(run, {
  target: "#pt"
});

Included

Repeatable renders
Control the frame, input, parameters, and random seed when a stable result matters.
Classic demos
Render a tested subset of unchanged demos through the compatibility loader.
CLI and API
Use the ptsjs command or call renderScene() from Node.
Structured results
Request JSON output for build scripts, automation, and agents.
