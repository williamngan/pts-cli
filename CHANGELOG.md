# Changelog

## 0.1.0 - Unreleased

### Added

- Deterministic SkiaCanvasSpace with explicit frame rendering.
- Pts CanvasForm integration through SkiaCanvasForm.
- Pts revamp baseline with typed form.space and preserved text-width estimator
  modes.
- Actionable compatibility failure when the older npm Pts implementation is
  resolved.
- PNG, JPEG, WebP, raw buffer, file, and data URL exports.
- Font normalization for skia-canvas.
- Skia Canvas, Image, and ImageData drawing support.
- Player lifecycle, resize, refresh, disposal, and export-race guards.
- ESM and CommonJS builds with strict consumer declaration tests.

### Deferred

- SVG and PDF adapter output.
- Browser scheduling, interaction, and offscreen CanvasSpace APIs.
